# User Manual

## Introduction
The Student Management System is a web-based application designed to manage student data, class schedules, and grades.

## Getting Started
1. Open a web browser and navigate to the application URL.
2. Log in with your username and password.

## Student Profile
1. Click on the "Student Profile" tab.
2. View student information, including name and grade.

## Class Schedule
1. Click on the "Class Schedule" tab.
2. View the list of classes and their corresponding teachers.

## Grade Report
1. Click on the "Grade Report" tab.
2. View the list of grades for each student.
