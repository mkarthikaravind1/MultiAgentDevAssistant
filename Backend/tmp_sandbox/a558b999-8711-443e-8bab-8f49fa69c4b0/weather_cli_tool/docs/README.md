# Weather CLI Tool
## Introduction
The Weather CLI Tool is a command-line interface application designed to scrape weather data from a specified source and save it to a CSV file. This tool utilizes BeautifulSoup for web scraping, pandas for CSV export, and click for CLI interface creation.
## Requirements
* Python 3.8 or higher
* BeautifulSoup
* pandas
* click
## Installation
To install the required libraries, run the following command:
```bash
pip install -r requirements.txt
```
## Usage
To use the Weather CLI Tool, navigate to the project directory and run the following command:
```bash
python main.py --help
```
This will display the available options and usage instructions.
## Features
* Scrape weather data from a specified source
* Save weather data to a CSV file
* Customizable CLI interface using click
